# Astro Inc Website

Static, Vercel-ready catalogue website for Astro Inc.

## Pages
- `index.html` — homepage
- `products.html` — searchable/filterable catalogue
- `product.html?id=...` — reusable product detail page
- `quote.html` — quote-request basket that sends the list to WhatsApp

## Deploy to Vercel
1. Upload this folder to a GitHub repository.
2. In Vercel, choose **Add New → Project** and import the repository.
3. Framework preset: **Other**.
4. No build command is required.
5. Deploy.

## Updating products
Product data is stored at the top of `app.js` in the `PRODUCTS` array. Add/update the name, price, description, image, brand, model and category there.
